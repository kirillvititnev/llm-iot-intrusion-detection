Ты выступаешь как Python-разработчик и специалист по машинному обучению в области анализа сетевого трафика.

Нужно создать полноценное Python-приложение для классификации вредоносного IoT-трафика на основе датасета IoT Intrusion Detection Dataset с Kaggle.

Требования к приложению:

1. Загрузить CSV-файл с датасетом из локальной папки data/raw/.
2. Автоматически определить целевой столбец с меткой класса. Если целевой столбец не найден однозначно, вывести список столбцов и попросить пользователя указать имя целевого столбца.
3. Провести первичный анализ данных:
   - размер датасета;
   - список признаков;
   - количество пропусков;
   - распределение классов.
4. Выполнить предобработку:
   - удалить или обработать пропуски;
   - закодировать категориальные признаки;
   - разделить данные на train/test;
   - масштабировать числовые признаки, если это необходимо.
5. Обучить минимум две модели:
   - Random Forest;
   - Logistic Regression или Decision Tree.
6. Рассчитать метрики:
   - accuracy;
   - precision;
   - recall;
   - F1-score macro;
   - confusion matrix.
7. Сохранить результаты в папку results/.
8. Сохранить лучшую модель в файл models/best_model.pkl.
9. Код должен быть воспроизводимым, с random_state=42.
10. Код должен быть оформлен как один Python-файл, который можно запустить командой:

python src/generated_app.py

11. Добавь комментарии к основным этапам кода.
12. В конце программы выведи краткий текстовый вывод о том, какая модель показала лучший результат.

Важно:
- не используй несуществующие библиотеки;
- не допускай утечки данных между train и test;
- не обучай модель на целевом столбце;
- если классов больше двух, используй multiclass classification;
- код должен быть готов к запуску после установки pandas, numpy, scikit-learn, matplotlib, seaborn, joblib.
