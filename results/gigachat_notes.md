# GigaChat

Для GigaChat использовался тот же русскоязычный промпт, что и для YandexGPT. Полный текст промпта находится в файле `prompts/prompt_ru.md`.

## Второй запуск

После уточняющего промпта GigaChat исправил ошибку с жестко заданным именем CSV-файла. Код успешно нашел и загрузил файл `IoT_Intrusion.csv`.

Однако на следующем этапе возникла методологическая ошибка: программа не смогла корректно определить целевой столбец. Вместо столбца `label` код предложил выбрать один из бинарных признаков сетевого трафика, например `HTTP`, `TCP`, `UDP`, `ICMP` и другие.

### Причина

Функция `find_target_column()` искала потенциальные целевые столбцы по количеству уникальных значений, используя условие `unique_vals <= 10`. В датасете IoT Intrusion целевой столбец `label` содержит больше 10 классов, поэтому он не был выбран как кандидат.

### Комментарий

Ошибка показывает, что GigaChat неверно интерпретировал задачу многоклассовой классификации. Для данного датасета целевой столбец должен определяться по названию `label`, а не по количеству уникальных значений.



## Финальный запуск после уточняющих промптов

После второго уточняющего промпта GigaChat корректно определил целевой столбец `label` и смог выполнить программу до конца.

Программа выполнила:
- автоматический поиск CSV-файла в папке `data/raw/`;
- загрузку датасета `IoT_Intrusion.csv`;
- определение целевого столбца `label`;
- первичный анализ данных;
- предобработку признаков;
- обучение моделей;
- расчет метрик;
- сохранение результатов;
- выбор лучшей модели.

### Предупреждения

Во время выполнения появились предупреждения scikit-learn:

```text
ConvergenceWarning: lbfgs failed to converge after 1000 iteration(s)
Это предупреждение связано с Logistic Regression. Модель не успела сойтись за заданное число итераций. Программа при этом не завершилась с ошибкой.
Также появились предупреждения:
UndefinedMetricWarning: Precision is ill-defined and being set to 0.0 in labels with no predicted samples.
Они означают, что для части редких классов модель не сделала ни одного предсказания. Это связано с сильным дисбалансом классов в датасете.

##Вывод
GigaChat смог сгенерировать рабочий ML-пайплайн, но только после уточняющих промптов. Основные ошибки были связаны с жестко заданным именем файла и неправильным определением целевого столбца. В отличие от YandexGPT, GigaChat изначально попытался определить target column по количеству уникальных значений, что оказалось некорректным для многоклассовой задачи.
